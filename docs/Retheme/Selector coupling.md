# Phase 0 — Selector-coupling report (Trilium v0.105.0)

Read-only audit. Line numbers are against `main` at `c775199ba6`. Coupling types:
1 = JS targets the selector · 2 = JS measures CSS-controlled geometry · 3 = vendored library internals ·
4 = visibility / hit-testing / stacking / custom property read back · 5 = JS awaits a transition/animation.

"Safe" means colour, background, radius, box-shadow, opacity-at-rest and typography colour unless stated
otherwise. Anything that changes a box (width, height, padding, border-width, margin, font-size,
line-height, display, position, transform, overflow, contain, pointer-events, z-index) is called out.

Two global mechanisms cut across every surface; read them first.
